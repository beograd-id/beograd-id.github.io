# Београд — визуальная идентичность

Статический сайт: открывается без сборки и сервера-бэкенда.

## Структура
- `index.html` — разметка всех экранов
- `css/style.css` — стили
- `js/deck.js` — листание экранов (колесо/трекпад, свайп, клавиши, меню, адреса #home #city #project #districts)
- `js/hero.js` — первый экран: фигуры и погода (Open-Meteo, обновляется раз в 30 минут)
- `js/history.js` — экран «о городе»
- `js/project.js` — экран «о проекте»
- `js/districts.js` — экран «общины»
- `js/reveal.js` — появление элементов при переходе на экран (что и как выезжает — список в начале файла)
- `fonts/`, `hero/`, `img/`, `art/`, `ph/`, `gerb/`, `logos/` — шрифты и картинки

## Новый экран
Добавьте `<section class="slide" data-hash="имя" data-theme="light|dark|red">…</section>` внутрь `#deck` — листание подхватит его само.

## Посмотреть локально
В папке сайта: `python3 -m http.server 8000`, затем открыть http://localhost:8000
(двойной клик по index.html тоже работает, но погода и шрифты надёжнее грузятся через сервер).

## Опубликовать на GitHub Pages
Загрузить содержимое папки в репозиторий (например, belgrade-guide), Settings → Pages → Deploy from branch → main / root.
